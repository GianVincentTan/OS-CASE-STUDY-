# OS-Case-Study-Instructions

1. Open the executable file named **CASE_STUDY_OS.html** using your preferred web browser.
2. Select the CPU Scheduling Algorithm you want to simulate.
3. Enter the required data such as:
   * Burst Time
   * Arrival Time
   * Priority Value (if applicable)
   * Quantum Time (if applicable)
4. Add or remove processes depending on the number of processes you want to test (minimum of 3).
5. Click the **Run Simulation** button to generate and display the results.
